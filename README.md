# K K Sales Website

A lightweight, static organization website for K K Sales, built with HTML5, CSS3 and vanilla JavaScript.

## Deploy

Upload this folder to a GitHub repository and import it into Vercel. No build command, dependencies or environment variables are required; `index.html` is the entry point.

## Before publishing

- Replace `ADD_VERIFICATION_CODE_HERE` in the `<head>` of both HTML files with the Google Search Console verification code when available.
- Confirm the canonical URLs use the final production domain.
- When an app is released, duplicate an application card in `index.html`, add its real icon and store link, and create its matching policy at `privacy/app-name.html`.

## Contact form

The contact form intentionally opens the visitor’s default email application with a pre-filled message. It does not send or store data on the website.
